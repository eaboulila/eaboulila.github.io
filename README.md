# Elsayed Aboulila — Online Portfolio

A responsive, static personal portfolio website for Data Analytics, Business Intelligence, AI, and Machine Learning opportunities.

## Selected platform: GitHub Pages

GitHub Pages is a suitable platform for this portfolio because it publishes static HTML, CSS, and JavaScript files directly from a GitHub repository. It is especially relevant to a technical profile because the same GitHub account can host both project repositories and a personal website. GitHub Pages sites are publicly accessible, so review the contact details and all public content before publishing.

## Publish the site with GitHub Pages

1. Sign in to GitHub as `eaboulila`.
2. Create a **public** repository named `eaboulila.github.io` (if you do not already have a repository with that name).
3. Extract this ZIP file. Upload the contents of this folder—not the enclosing folder—into the repository root. The `index.html` file must be at the root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then save.
7. Wait for the Pages deployment to complete. The expected personal-site address is `https://eaboulila.github.io/`.
8. Open the published site on both desktop and mobile and test every navigation and project link.

The website is provided as a ready-to-publish package; it has **not** been published to GitHub or made publicly available by this package. The expected URL will work only after the repository is created and deployment succeeds.
